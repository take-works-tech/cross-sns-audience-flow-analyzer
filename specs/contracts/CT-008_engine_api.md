# Contract: EngineAPI

### CT-008 - EngineAPI
- purpose: the frozen HTTP surface between the web app and the engine — the OpenAPI 3.1 document at packages/contracts/openapi.yaml, generated by FastAPI (E-011 (T2)) and consumed only through the TypeScript client generated by openapi-typescript (INV-009)
- schema: schema/CT-008.json
- version: 1.0.0
- strictness: after the freeze at backend completion (development-stack step 4), the surface changes only additively; a breaking change is a new version of this contract, never an edit to the frozen one
- compatibility: the web app is built against the exact openapi.yaml it vendors, so a reader of an older version may assume nothing — client regeneration is part of every contract bump
- migration: regenerate the TypeScript client from the new openapi.yaml and rebuild the web app; there is no runtime version negotiation
- decidedness: Bounded

schema/CT-008.json describes the contract manifest — where the surface lives and its freeze state — not the API payloads. The payload shapes that surface serves are CT-001, CT-002, CT-004, CT-006, and CT-007; the openapi.yaml is their single wire-format home. No hand-written request path may exist in the web app (INV-009): the generated client is the only caller.
