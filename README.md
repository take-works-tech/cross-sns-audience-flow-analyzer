# cross-sns-audience-flow-analyzer

Web app that connects SNS accounts (YouTube / Instagram / TikTok / X) and arbitrary URLs, then
visualizes audience inflow between them as an interactive network graph with flow animation.

- Human-readable spec: `Cross-SNS Audience Flow Analyzer 仕様書 v1.1.md` (JA; v1.0 is the original input)
- Canonical machine-checked specs: [specs/](specs/) — lint with `python validate/check_specs.py`
- UI reference: [docs/mockups/ui-mockup.html](docs/mockups/ui-mockup.html) — all 11 screens
- Stack: Next.js 16 + React 19 + TypeScript + Tailwind v4 + @xyflow/react ·
  FastAPI + Celery + PostgreSQL/TimescaleDB + Redis (see `docs/development-stack.md`)

Status: frontend implemented against mock data; the analysis engine is not built yet.

## Frontend

```sh
cd apps/web
npm ci
npm run dev     # http://localhost:3000
npm test        # vitest
npm run build
```

## Specifications

```sh
python validate/check_specs.py            # must report 0 findings
python validate/check_specs.py --report   # release-readiness summary
```

## Agent environment

`.claude/` holds the Claude Code environment (rules, hooks, skills, agents), generated by the
author's `claude-agent-env-design` toolkit. Frontend visual quality is enforced by a chain of
skills; two pieces are **not vendored here** and must be installed once:

```sh
bash scripts/install-external-skills.sh   # third-party skills, fetched from upstream
```

and, from inside Claude Code:

```
/plugin install frontend-design@claude-plugins-official
```
